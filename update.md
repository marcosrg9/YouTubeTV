YouTube TV ha sido actualizado a la versión 3.0.0. Esta versión incorpora grandes mejoras.

### Soporte para resoluciones mayores
A partir de ahora, se podrá visualizar contenido hasta 4K, y en algunos vídeos 8K.

### Una interfaz de usuario renovada
A partir de ahora, YouTube TV se mostrará con una nueva interfaz más actualizada y atractiva (Cobalt).

### Nueva ventana de configuración
Se ha actualizado todo el sistema de configuración para que el diseño encaje con el de YouTube TV y la brecha de experiencia sea ínfima.

A continuación se ha integrado más opciones:

- Capacidad para desactivar la transmisión de contenido desde el teléfono o bien reemplazar el nombre de dispositivo integrado.
- Capacidad de decidir si se desea recordar el tamaño y posición de la ventana cuando se vuelva a abrir.
- Mantener YouTube TV cargado en segundo plano, esperando a que algún dispositivo se conecte.

### Soporte para Widevine
YouTube TV ha integrado soporte para Widevine, de manera que a partir de ahora, ningún fallo de reproducción podrá ser repercutido por este problema. Se agradece enormemente a los contribuidores de Castlabs EVS.
